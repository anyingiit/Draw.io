## 关于本项目

个人存放的 draw.io 图表文件集合，描绘的是另一个独立项目——基于 Golang 和 React 的内网资源管理系统——的设计，本仓库自身不包含任何应用程序源代码。仓库中共有四个 `.drawio` 文件——`GoReactInternalResourceClass.drawio`（类图）、`GoReactInternalResourceEntityRelationshipDiagram.drawio`（实体关系图）、`GolangReactInternalResourManageDatabasePhysicalDesign.drawio`（数据库物理设计图），以及一个中文命名的后端图表，其文件名的含义就是"基于 Golang 和 React 的内网资源管理软件——后端"——此外还有一个保留默认文件名的 `Untitled Diagram.drawio`。仓库里没有任何包清单、入口点或测试套件；该仓库本身在 GitHub 上已被标记为存档（archived）。

仓库中其余的文件都是围绕这些图表的常规开源样板：issue 和 pull request 模板、Dependabot 配置、变更日志，以及常见的社区健康文件。

计划中的功能与已知问题，见 [open issues](https://github.com/anyingiit/Draw.io/issues)。

## 开始使用

### 环境要求

- 一个兼容 diagrams.net/draw.io 的查看器或编辑器，用来打开 `.drawio` 文件——例如桌面客户端、VS Code 的 "Draw.io Integration" 扩展，或 diagrams.net 网页版——比如用它打开 `GoReactInternalResourceClass.drawio`。
- 别无所需：仓库中没有任何包清单（没有 `package.json`、`pyproject.toml`、`go.mod` 等），也没有需要安装、编译或运行的应用程序代码。

### 安装

```sh
git clone https://github.com/anyingiit/Draw.io.git
cd Draw.io
```

然后直接打开任意 `.drawio` 文件，例如 `GoReactInternalResourceEntityRelationshipDiagram.drawio`，用你选择的查看器打开即可——没有其他需要构建或安装的步骤。

## 用法

用兼容 diagrams.net 的查看器或编辑器打开任意 `.drawio` 文件——例如 `GolangReactInternalResourManageDatabasePhysicalDesign.drawio`——即可查看或编辑该图表。这里没有命令行界面、服务或构建产物；图表本身就是最终产出。
